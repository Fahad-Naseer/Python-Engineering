# Python Engineer 🐍

Daily Python practice repo — solving exercises consistently to build a strong foundation for **ML/MLOps** and **Python automation for Cloud Engineering**.

## 🎯 Goals

- Strengthen core Python fundamentals (data structures, OOP, algorithms)
- Build the Python base needed for ML/MLOps work later on
- Practice Python automation patterns relevant to Cloud Engineering (scripting, APIs, file/system automation)
- Stay consistent with daily practice, tracked publicly for accountability

## 📁 Structure

```
python-engineer/
├── exercises/
│   ├── easy/
│   ├── medium/
│   └── hard/
├── automation/          # cloud/automation-focused scripts
├── notes/                # short notes on concepts learned
├── PROGRESS.md           # daily log table
└── README.md
```

- **exercises/** — solutions grouped by difficulty (or swap for topic-based folders like `strings/`, `loops/`, `oop/` if that fits your source better)
- **automation/** — separate folder once you start Python-for-cloud-automation exercises, so it doesn't mix with pure practice problems
- **notes/** — optional, one short `.md` per tricky concept (helps later when reviewing for interviews)
